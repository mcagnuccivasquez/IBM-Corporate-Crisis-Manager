# A5 — Report Writer (narrative + PDF)

> **New chat? Load in this order:** `AGENTS.md` → `STATUS.md` → `PROJECT.md` (esp. §4, §7) → this file.
> **Owns:** `src/agents/a5_report.py`, `src/prompts/a5_report.md`, `src/report/` (`template.html`, `style.css`, `render.py`), `tests/test_a5_*.py`.

## 1. Mission
Turn the validated CaseState vN (+ vN-1) into **Crisis Management Report vN**: the same structure every time, readable by an executive, and **one PDF per version**.
A5 adds **no new facts or judgements**. It only summarises and formats what the other agents produced.

## 2. Split of work (cheap and consistent)
| Part | Done by | Why |
|---|---|---|
| Tables (evidence, risk matrix, actions, stakeholders, sources, changelog lists) | **code** (Jinja2 straight from CaseState) | exact, no hallucination risk |
| Narrative: Situation (≤150 words), "What changed and why" (≤120 words), Executive summary (≤80 words), close-out summary | **LLM** (low effort) | readability |
| HTML → PDF | **code** (Playwright Chromium `page.pdf()`) | identical layout every version |

LLM output schema:
```json
{ "executive_summary": "...", "situation": "...", "changes_summary": "...", "closure_summary": null }
```
Every sentence of the narrative must be traceable to CaseState fields. Cite IDs in brackets, e.g. `[C-007, U-03]`.

## 3. Fixed report structure (PROJECT §7)
0. **Header band**: ACME · Crisis Management Report · CASE-001 · **v3** · timestamp · status · big badge **Risk: High → High** (colour by level) · "Evidence confidence: Moderate" (separate, smaller badge) · Focus
1. Situation (+ executive summary box)
2. Evidence: three tables: **Confirmed** / **Unconfirmed** / **Disproved or misleading** (claim, strength, sources, since version, changed?)
3. Risk and reasons: S×L matrix per domain, floors applied, reasons list, link to Appendix B
4. Impacts: one subsection per domain incl. "if left unaddressed"
5. Stakeholders table
6. Action plan: table sorted by priority, then focus; status chip (proposed/approved/in progress/completed/verified ✓/verified ✗/dropped); options considered as an expandable sub-row
7. Outlook if priority actions succeed (residual risk badge, assumptions, cannot estimate, pattern warnings)
8. Changes since v(N-1) (risk from→to + reason even if unchanged; new evidence; claim changes; action changes) and **Open questions** (owner)
9. *(Closed only)* Remaining risk · Open actions · Conditions for reopening
- Appendix A Sources cited (ID, title, date, category, current/historical) · Appendix B Risk method (static text from PROJECT §6) · Appendix C QA notes (unresolved A4 issues) + agent trace (which agents ran, tokens)

v1 has no previous version: section 8 says "Initial assessment".

## 4. Rules
- No new facts, numbers, or recommendations. If a field is empty, print "None reported" rather than inventing content.
- Wording: neutral, no blame. Mark drafts (statements) as **DRAFT – requires approval by …**.
- Footer on every page: "Decision-support draft generated by the ACME Crisis Manager. Does not execute recalls, notifications or public statements." + page x/y + version.
- File name: `cases/<case_id>/report_v<N>.pdf`. Never overwrite an existing version.
- Print-friendly CSS: A4, `@page` margins, table headers repeat across pages, no row split mid-row, colour + text label for risk (readable in black and white).

## 5. Draft runtime system prompt (narrative only)
```
You write the narrative parts of ACME's Crisis Management Report from the case state provided. Use only information
in the case state; do not add facts, figures, judgements or recommendations. Write for a busy executive: plain,
neutral, specific. Cite claim, source and action IDs in square brackets. In "what changed", always state the previous
and current risk level and the reason, including when the level did not change. Respect the word limits.
```

## 6. Acceptance tests
- [ ] Same CaseState rendered twice → identical PDF layout (only the timestamp differs).
- [ ] Report v2 shows Risk prev→current, new sources, claim and action changes, and explains an unchanged level.
- [ ] All 9 sections + appendices present. Closed case shows section 9.
- [ ] A narrative containing a number not in CaseState → caught by a simple check (extract numbers from the narrative, verify they appear in the state JSON).
- [ ] PDF opens on Windows/Mac; long tables paginate cleanly.
